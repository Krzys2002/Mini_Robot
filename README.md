# Micro-robot swarm project

The desktop application is in [Mini_Robot](Mini_Robot/README.md). The
`T1-ESP-C6`, `T1-ESP-S3`, and `Mini_Robot/firmware/ble-lifecycle` directories
contain separate firmware projects.

- [Project documentation](Mini_Robot/docs/README.md)
- [Build and testing](Mini_Robot/docs/development/README.md)
- [Optional local Graphify navigation](Mini_Robot/docs/development/graphify.md)
- [Repository agent instructions](AGENTS.md)

Graphify is development tooling only; it is not needed to build or run the robot
application. Current application build commands run from `Mini_Robot/`.
